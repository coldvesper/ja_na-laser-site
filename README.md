# Ja_Na_Laser

Статический сайт на HTML, CSS и изображениях. Сборка и установка зависимостей не требуются.

## Публикация через GitHub Pages

1. Загрузите файлы проекта в корень репозитория GitHub.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку, в которую загружен сайт, и папку **/(root)**, затем нажмите **Save**.
5. После публикации GitHub покажет ссылку на сайт в этом же разделе.

Главная страница проекта — `index.html`. Внутренние ссылки и ресурсы используют относительные пути, чтобы сайт работал как в корне GitHub Pages, так и в Pages-проекте с адресом вида `https://<пользователь>.github.io/<репозиторий>/`.
